# GraphQL Profile Page

A personal profile page that queries and displays school data via the GraphQL API.

## What it does

- Authenticates via a login page (username or email + password) using JWT
- Queries your school data through the GraphQL endpoint
- Displays your profile with at least three information sections (XP, audits, grades, etc.)
- Generates statistics using SVG graphs (progress over time, XP by project, etc.)

## Tech

- Vanilla JS / HTML / CSS
- GraphQL (normal queries, nested queries, queries with arguments)
- SVG for graphs
- JWT / Bearer authentication
